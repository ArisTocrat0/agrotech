    Укажите только известные координаты. Это положение камеры или дрона в момент съёмки, а не точное положение мусора или очага.

    Одна пара применяется ко всем выбранным фото. Для разных мест съёмки используйте JSON по именам файлов. Если поля и JSON пусты, сервер может использовать GPS из EXIF фото.

    Формат JSON

    Ключ — точное имя выбранного файла. Для фото укажите latitude, longitude, source: "operator_capture_position". Значения должны соответствовать реальной съёмке. Используйте JSON либо общие поля координат.
